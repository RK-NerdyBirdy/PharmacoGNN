# PharmaGNN frontend implementation plan

Goal: implement the approved seven-screen Figma flow in the existing vanilla frontend.
Architecture: preserve separate HTML screens and shared CSS. Add a versioned demo store with a replaceable fixture provider and user provider; keep UI rendering separate from scores and persistence. No backend or auth changes.

- [ ] Add and test persisted regimen, selected pair, context, candidates and draft simulation.
- [ ] Match the supplied Figma SVG sources; implement hover ripple and reversible scroll capsule/dots/waves, including reduced motion.
- [ ] Connect medicine add/remove, keyboard matrix selection, context comparison, evidence, candidates, simulation, export and reset.
- [ ] Validate desktop/mobile, empty/unknown state and complete navigation; document testing.
- [ ] Commit and push the current dev branch as requested.

Source design: https://www.figma.com/design/QEKWfxIxuE5AtVuQn3Id9v
Scope: hardcoded synthetic demo fixtures and replaceable user; no authentication or real clinical inference.
